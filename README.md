### 📐 มาตรฐานขนาดภาพข่าว (Image Specifications)

| ประเภทภาพ | สัดส่วน (Ratio) | ขนาดพิกเซล (กว้าง x สูง) | การนำไปใช้งาน |
| :--- | :---: | :---: | :--- |
| **ภาพปกบทความ (Featured Image)** | **16:9** | **1200 x 675 px** | ใช้เป็นรูปปกหลักของข่าว และรูปพรีวิวเวลาแชร์ลงโซเชียล |
| **ภาพเนื้อหาแนวนอน (Content Landscape)** | **3:2** | **640 x 427 px** | ภาพข่าวเหตุการณ์ทั่วไป, บรรยากาศงาน, ทิวทัศน์ (ไม่ล้นคอลัมน์) |
| **ภาพเนื้อหาจัตุรัส (Content Square)** | **1:1** | **600 x 600 px** | ภาพบุคคล Portrait, อาหาร/ของกิน, ของฝาก, ภาพเจาะวัตถุ |

---

### ⚙️ ข้อกำหนดก่อนนำภาพขึ้นเว็บไซต์
1. **นามสกุลไฟล์:** ส่งออกเป็น `.webp` (ดีที่สุด) หรือ `.jpg`
2. **น้ำหนักไฟล์:** ควบคุมขนาดไฟล์ **ไม่เกิน 80–100 KB ต่อภาพ** เพื่อความเร็วในการเปิดอ่านบนมือถือ
3. **การวางในเนื้อหา:** เลือกตำแหน่งภาพเป็น **Align Center (กึ่งกลาง)** หรือ **None (ไม่ระบุ)** เสมอ
